# Knowledges — Tài nguyên khóa học

Đây là **bài học của khóa học** (Module 1 → Module 4), dùng để soạn ra các agent trong
`qa-*/`.

> **Agent KHÔNG đọc thư mục này lúc chạy.** Mọi tri thức cần thiết lúc thực thi đã được nội hoá
> vào `qa-*/skills/*.md` và `shared/QA_STANDARD.md`.

## Vì sao tách ra

| | Knowledges/ | qa-*/skills/ |
|---|---|---|
| Đối tượng đọc | Người học | AI lúc chạy |
| Nội dung | Giải thích, ví dụ cụ thể (voucher ShopGo…), quota bài tập | Quy trình + format + ràng buộc |
| Được sửa khi | Cập nhật giáo án | Cập nhật cách agent làm việc |
